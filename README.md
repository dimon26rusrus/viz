# FORM — Визуализация для продаж

Готовый одностраничный сайт-портфолио для студии архитектурной визуализации.

## Что внутри

- `index.html` — главная страница.
- `styles.css` — вся стилизация и адаптивная верстка.
- `assets/hero.jpg` — локальная фотография для первого экрана.

## Как разместить на сервере

### Вариант 1: обычный хостинг с панелью управления

1. Скачайте архив и распакуйте его.
2. Откройте файловый менеджер хостинга.
3. Перейдите в папку сайта — обычно это `public_html`, `www` или `htdocs`.
4. Загрузите туда **содержимое** папки проекта: `index.html`, `styles.css` и папку `assets`.
5. Откройте домен в браузере.

### Вариант 2: VPS / сервер по SSH

Загрузите содержимое проекта в корневую папку сайта, например:

```bash
/var/www/example.com/
```

Для Nginx в конфигурации сайта укажите:

```nginx
root /var/www/example.com;
index index.html;
```

После загрузки проверьте, что файл открывается по адресу:

```text
https://ваш-домен.ru/index.html
```

## Что заменить перед публикацией

- В `index.html` замените `hello@form-visuals.ru` на вашу почту.
- При необходимости замените ссылки `Instagram ↗` и `Behance ↗` на реальные ссылки.
- Чтобы использовать собственную фотографию, замените файл `assets/hero.jpg`, сохранив это имя.
- Для работы формы обратной связи понадобится подключить внешний сервис или серверный обработчик — сейчас кнопки ведут на email через `mailto:`.

## Фото

Фотография сохранена локально из Unsplash, поэтому сайт не зависит от внешнего URL изображения. Перед коммерческим использованием проверьте актуальные условия лицензии и при необходимости добавьте атрибуцию фотографа.
